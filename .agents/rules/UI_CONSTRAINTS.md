# UI Design Constraints

1.  **Monochrome Baseline**: Use a strict, high-contrast monochrome palette. Backgrounds must be pure white (`#ffffff`) or flat very light gray (`#f9fafb`). Text must be near-black (`#111827`).
2.  **Accent Color Limit**: Use exactly ONE accent color (e.g., standard red `#ef4444`) strictly for primary call-to-action buttons or destructive warning states (e.g., SCM Detected).
3.  **Data Density**: Prioritize compact lists and data tables over spacious grid cards. The UI should look like a dense, functional dashboard engineered for heavy daily use.
4.  **No Decoration**:
    *   No gradients, glowing effects, or backdrop blurs.
    *   No box-shadows. Use 1px solid borders (`border-gray-300` or `border-black`) to separate elements.
    *   Maximum border radius allowed is 2px.
    *   Everything must be left-aligned for readability (no centered text).
